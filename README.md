# belousov-zhabotinsky.

Interactive 2D Belousov–Zhabotinsky reaction visualizer

## Controls & Metrics

- **`α` (0.85–1.55)** - reaction rate scaling parameter.
- **`spd` (1–8)** - simulation steps per frame.
- **`gen`** - simulation generation count.
- **`a/b`** - mean concentrations of active reactants $A$ and $B$.
- **Interactions** - click or drag across the canvas to drop catalyst perturbations.
- **Shortcuts** - `Space` to pause/resume, `P` to drop catalyst pulse, `R` to restart with a random field.
